## agent v0.3.1
- WhatsApp QR · Telegram 전화코드 **웹 로그인**(마법사에서 클릭만)
- 연결 계정 **삭제**(CRM 웹에서)
- **이메일 채널**(Gmail OAuth, 토큰은 이 컴퓨터에만 저장)
- WhatsApp @lid 스레드 **이름 실명화**(표시이름/전화번호)
- 마법사 서버에 **버전/업데이트 엔드포인트** → 이후 버전은 CRM 웹의 [업데이트] 버튼으로
- self-update 엔드포인트 **Origin 화이트리스트**(CSRF 완화)

설치: macOS `install.command` 우클릭→열기 · Windows `install.bat` 실행.
