# Buyer CRM Messenger Lab

메신저 기능만 독립적으로 공부하고 쌓기 위한 lab 프로젝트입니다.

## 00 Scaffold

현재 단계는 기능이 없는 최소 화면입니다.

- Next.js App Router
- 조용한 CRM 스타일의 좌측 사이드바
- `메신저` 탭 하나
- 빈 메신저 작업 화면

아직 없는 것:

- thread/message 모델
- mock data
- buyer/customer 연결
- API
- LLM
- Supabase
- 외부 채널 연동

## Commands

```bash
npm install
npm run dev
```
